# 23. The frame and the home it might become

The parenthesis in (D)Home keeps two scales in view. This project is making a dome frame. The larger ambition is useful shelter shaped by that frame. The next decisions include the envelope, openings, drainage, insulation, ventilation, services, interior space, and maintenance access.

The project already explores many of these subjects. Dome Creator can show frames, panels, interiors, and site arrangements. Other lessons examine energy, material quantities, assembly flow, and alternative shapes. Use those tools to illustrate questions the frame creates, while labeling conceptual configurations so a reader does not mistake an image for a completed building detail.

The seam has to be considered again when a skin is introduced. Water follows exterior geometry and discontinuities, not the simplicity of a frame diagram. An opening introduces edges where layers end or turn. A service penetration has to be coordinated with the envelope and with the structure. Those are design topics to develop explicitly in a later phase.

Space also deserves a measured description. The base polygon, the curved wall profile, and the location of the useful head-height zone influence furniture and circulation. A floor area quoted from an enclosing circle tells only part of that story. Include a plan and a section when describing a proposed interior.

At the fortnight's end, name the achieved milestone precisely. If the frame is standing, describe that accomplishment and its remaining work. If a problem has delayed the frame, describe the problem and what the experiment established. The title can hold ambition without requiring the field record to invent completion.
