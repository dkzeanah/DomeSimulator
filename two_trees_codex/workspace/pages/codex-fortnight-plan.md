# 24. Plan the fortnight, then record the difference

The schedule is a working hypothesis. It assumes the source timber, site arrangements, appropriate design decisions, equipment, and relevant preparation are available. List preparation honestly beside day one. Work that took place before the clock still belongs to the cost and history of the project.

| Days | Proposed focus | Evidence that closes the stage |
| --- | --- | --- |
| 1–2 | Verify source inventory and freeze the first physical configuration | Measured section ledger and saved model |
| 3–4 | Trial stock processing and representative corners | Accepted samples, measured losses, revised allowance |
| 5–7 | Produce, inspect, and assign the remaining wedge blanks | Actual accepted member inventory |
| 8–10 | Build and check both triangle families | Panel register and inspection record |
| 11 | Verify the base, equipment, connections, and assembly readiness | Stage review against the actual assembly plan |
| 12–13 | Assemble through planned supported stages | Stage photographs, corrections, dimensional checks |
| 14 | Record the achieved condition and the remaining work | Final inventory, photographs, and truthful outcome |

These are allocations, not daily quotas that override conditions. An unresolved trial corner is a reason to move the batch, because repeating an uncertain detail produces more uncertainty. An interruption should appear in the schedule rather than be hidden by counting only the hours when the saw was running.

Each field page asks for the same small set of facts and one different story question. The facts make the process comparable. The question keeps the narrative from becoming only a spreadsheet. Include a photograph that proves a change, even when the change is a correction or a rejected piece.
