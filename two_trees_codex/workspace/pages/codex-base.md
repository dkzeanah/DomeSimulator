# 21. Give the frame a place to stand

The base ring is a ten-sided boundary in the selected hemisphere. It must be laid out from a consistent center and reference dimensions. A radius drawn on the ground locates the circumcircle; the segments joining the base vertices locate the polygon. Record which reference was used at every check.

The structural path continues from the panels through their connections and into the support and anchorage system. The base is therefore part of the design, even though the two trees are supplying the wedge members above it. Record the actual foundation or support approach, site information, and the design responsible for uplift, sliding, settlement, and the applicable loads.

Check the base layout before accepting panel fit as evidence about the dome. A misplaced support can make correct panels appear wrong. An improvised adjustment in one seam can then distribute that error through several others. Keep the layout measurements separate from the panel acceptance measurements so the source of a mismatch can be found.

The book should include a plan-view plate with base vertex IDs and reference dimensions from the chosen model. Pair it with an actual site photograph showing the same labels. This pair is more useful than a generic rendering because it connects the drawing to the place where the assembly must close.

Any doorway that interrupts the frame or base changes the local arrangement. Describe the intended opening as an explicit design variant. Do not silently remove members from the forty-triangle scheme while continuing to quote its original topology and stock count.
