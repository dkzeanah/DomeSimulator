# 27. The tools that made the questions visible

DomeSim is a workshop of related tools. Their value to the book is that they make different parts of the same question visible. A film can introduce an idea; a physical solver can inspect a joint; a site designer can show how a frame might become a place to live.

| Project tool or study | Role in the book | Suggested image |
| --- | --- | --- |
| Raw Wedge Dome | Physical members, orientations, cut planes, seams, and jig | Four orientations and a close seam |
| 2V geometry / Masterclass | Sphere subdivision, factors, panel families | Topology beside panel ownership |
| Frankendome | Earlier experiments with varied triangular members | Dated prototype photograph and explanatory frame |
| Hex masterclass | Hexagon/pentagon cages and changes in panel shape | A labeled model plate |
| Zome masterclass | A related form built from rhombi and generating directions | Polar zome plate |
| Dome Creator | Panels, interior concepts, services, and site arrangement | Selected saved scene with configuration |
| Dome Forge | Configurable build variants, groups, layers, and jigs | A chosen design and layer comparison |
| Assembly Line | Material flow and the work of making repeated units | A scene tied to measured production stages |
| Presenter / video lessons | Explanatory sequence and narrative evidence | A still that communicates one claim |
| Beat and voice tools | Narration experiments and reusable short sequences | Script excerpt with the finished page it informed |

The atlas is not a claim that every depicted structure can use the same 120-piece inventory. The 2V panelized hemisphere owns that count. A hex cage and a zome have their own topology and material requirements. Keep their configuration labels visible when they appear in the same spread.

For each selected project still, retain the source tool, configuration, camera, date, and a caption saying what the image demonstrates. Rendered imagery can explain geometry very well. Actual build photographs establish what the author made. Use each where it carries the evidence the page needs.
