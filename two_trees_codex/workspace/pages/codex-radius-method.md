# 7. Method one: start with the radius you want

Choose a sphere radius R, then keep one unit throughout the calculation. If the radius is in feet and the working dimensions will be inches, multiply it by twelve before finding the chords.

The nominal relationships are A = R × fA and B = R × fB. For this project's exact generated 2V mesh, fA is approximately 0.618033989 and fB is approximately 0.546533058. The Sizing lab obtains these factors from the existing geometry module rather than keeping the rounded printed values as its authority.

The procedure is sequential. Record the desired radius. Generate both chord lengths. Confirm the forty-panel inventory. Select the member cross-section, orientation, and seam construction. Generate the physical model and inspect its actual stock lengths. Only then select raw blank lengths and allocate trees.

If a radius gives nominal edges that are inconvenient for the timber, the design still has options. A slightly smaller radius can reduce length demand. A different seam or corner setting can change the stock envelope. More usable source length may be available in a longer section. Each option must be checked through the same solver; none should be hidden inside an unexplained rounding choice.

Record three lengths for each member: the ideal chord, the finished physical stock envelope, and the blank required to fabricate it. The last includes whatever additional holding, trimming, and overfit stock the actual process needs. Zero extra allowance in the lab explicitly means that only the finished envelope is being checked.

When the stock plan is complete, export the actual simulator's bill of materials and cut schedule for the chosen configuration. The book can explain the reasoning, while that schedule preserves the geometry used for the build. Write the configuration and date beside any printed schedule so an older paper does not silently govern a newer design.
