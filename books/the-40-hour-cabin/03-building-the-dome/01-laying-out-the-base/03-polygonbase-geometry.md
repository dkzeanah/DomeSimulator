# Polygon/base geometry

The base of a 2V hemisphere is a ten-sided polygon, not a circle.

Ten vertices on the circle, and straight members between them.

THE NUMBERS

Ten base vertices, evenly spaced -- 36 degrees apart around the circle.

Ten base members between them, and on the reference build the base perimeter
is 60.0 feet, which makes each base member 6.0 feet. That is the same as the A
chord, and it is not a coincidence: the base edges of a 2V hemisphere are A
edges.

The polygon encloses 277.0 square feet. The circle through the same ten points
encloses 296.1.

Use the decagon figure for flooring. Use the circle only if you are working
out how much space the dome needs on site.

MARKING THE TEN POINTS

Do not step a chord round the circle with dividers. Error accumulates and the
tenth point will not land on the first.

Two better ways.

Measure the chord: mark one point, measure 6.0 feet along the circle's
circumference to the next, and so on -- but check at the halfway point that
you are diametrically opposite where you started.

Or divide by halving: mark two points at opposite ends of a diameter. Bisect
each half to get four. You cannot get to ten by halving, so this only takes
you so far -- but establishing an accurate diameter first and working from
both ends toward the middle beats stepping round in one direction.

THE CLOSING CHECK

The tenth base member should fit between the tenth vertex and the first
without being cut, forced, or persuaded.

If it does not fit, the error is spread through all ten and you should re-lay
the base rather than absorb it in one joint. A forced base ring pushes its
error up into every ring above it.
