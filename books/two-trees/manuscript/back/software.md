# Where the Tools Live

Every number in this book came out of software: the raw-wedge solver, the
tree model, the pinwheel arithmetic and the costing tables. That software
is not hiding, and it is not gone. It lives in one place, and this page is
the signpost.

**The codebase.** The geometry, the solver and the tables are published,
open source, at {{book.repo}}. Anyone who wants to check a number in this
book — or change the tree and rebuild every table around their own — can
run the same software that printed these pages.

**The Complete Edition.** The site sells *The 40 Hour Cabin: Complete
Edition*: the same method carried further — every finish, every material
and panel priced, the systems this paperback leaves out — together with
the codebase that computed all of it, and every future edition of that
book. It is the other half of the project this paperback introduces.

**The design session.** For one dome, designed with the author using the
project's own tools, the site also sells a one-on-one design session.

Nothing in this book was invented for the page. The numbers were computed,
the corrections were found by the same arithmetic, and the tools that did
it are one address away.
