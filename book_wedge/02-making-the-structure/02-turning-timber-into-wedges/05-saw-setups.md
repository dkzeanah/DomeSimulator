# Saw setups

A setup is a saw, a fence, a stop and a blade height, held constant while you
run a batch through it.

The number of setups in this build is small. The number of *cuts* is large.
That ratio is the thing to protect.

THE SETUPS YOU NEED

Splitting: a rip setup with a tall fence and a riving knife.

Length: a crosscut setup with a stop block, one for A members and one for B.

Butting ends: an angled crosscut, referenced off a fence at the butt angle.

Receiving faces: a shallow cut along the side of the member, referenced off
the same fence.

That is four setups for 120 members and about 300 cuts.

CHANGE THE SETUP AS SELDOM AS POSSIBLE

Every setup change is an opportunity for the new setting to be slightly
different from the old one.

If you do all sixty A lengths, then change to B, then change back because you
miscounted, the second batch of A members is not guaranteed to match the
first.

Do all of an operation. Count before you change. Then change once.

THE STOP BLOCK

A stop block sets length without measuring, which is the single biggest
accuracy win available.

Clamp it, cut one, check it, then cut the rest without measuring anything.

Check it again every tenth piece. Stop blocks creep -- the clamp relaxes, the
block gets knocked, sawdust builds up behind it. Ten pieces is often enough to
catch creep while it is still small.

AND THE THING THAT WILL BITE YOU

Sawdust behind the stop.

A sixteenth of packed dust between the workpiece and the stop makes every
subsequent piece a sixteenth long, and it accumulates invisibly over a batch.

Blow it out between pieces. Every piece. It takes a second and it removes an
entire category of error.
