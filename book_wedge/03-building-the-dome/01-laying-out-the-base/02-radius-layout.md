# Radius layout

A string and a stake will lay out a dome more accurately than most survey
equipment, provided the string does not stretch.

THE METHOD

Tie a non-stretch line to the centre nail. Mark it at the radius -- 116.4984
inches on the reference build, which is 9 feet 8.5 inches.

Swing it round and scribe a circle.

Every base vertex lands on that circle.

WHY THE LINE MATTERS

Ordinary string stretches. Over nine and a half feet, under the tension you
pull it at, mason's line can add most of an inch -- and it will add a
different amount each time depending on how hard you pull.

Use a steel tape, a fibreglass tape, or a wire. Something that returns the
same number twice.

Better still: use a rigid stick. Cut a piece of timber to exactly the radius,
pivot it on the centre nail, and mark from the end of it. A stick does not
stretch at all, and for a dome this size a stick is entirely practical.

CHECK IT BY CLOSING

Scribe the whole circle and come back to where you started. The line should
meet itself.

If it does not, your pivot has moved, and you should find out why before you
put ten vertices on it.

THE SECOND CHECK

Measure across the circle through the centre. It should be twice the radius:
19.416 feet.

Do that in four directions. All four should agree. If one is different, the
centre is not where you think it is.

Two minutes of checking here prevents a base ring that will not close, which
is a problem you otherwise discover with ten panels built.
