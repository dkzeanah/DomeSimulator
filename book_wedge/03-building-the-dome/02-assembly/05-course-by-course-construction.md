# Course-by-course construction

A 2V hemisphere goes up in three courses and a cap.

THE COURSES

Bottom: ten BAB triangles on the base ring, alternating up and down.

Middle: more BABs, closing the band between the base and the top ring.

Top: the ten AAA triangles, five of which form the ring immediately around the
apex.

Thirty BABs and ten AAAs, in that order, bottom to top.

WHY THIS ORDER

Each course rests on the one below, and each closed course is a rigid ring
that supports the next.

An open course is unstable. A closed one is a compression ring and it will
hold a lot.

So the rhythm is: set a whole course loosely, check it closes, fasten it,
raise the platform, next course.

CHECKING BETWEEN COURSES

Every time a course closes, check three things.

Is it level? The top edge of the completed course should be level all the way
round.

Is it round? Measure across, through the centre, in four directions. All four
should be the same.

Is it the right height? Compare against the geometry. Each course has a known
height and a known radius at its top edge, and the tool will print them.

Those three checks take ten minutes and they stop an error propagating
upward.

WHAT TO DO IF A COURSE WILL NOT CLOSE

Stop. Do not force it.

Measure the panels in that course against each other. If one is different, you
have found it.

If they all match, the error is below -- in the course underneath or in the
base layout -- and forcing this course will push it higher.

A dome that is forced closed at course two has a fight waiting at the apex,
and the apex is the worst place in the building to be arguing with geometry.
