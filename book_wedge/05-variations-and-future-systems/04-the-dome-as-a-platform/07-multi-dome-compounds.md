# Multi-dome compounds

One dome is a room. Several domes are a house, and the connection between
them is where the design problem lives.

WHY MULTIPLE RATHER THAN BIGGER

Because the frame line does not change.

Six second buildings priced off the same model differ only in which panels
are in the bays. A gym, a garage, a studio and a guest room are the same
frame, the same 120 members, the same column, and different infill.

That is the manufacturing argument and it only works at one size. A bigger
dome is a different frame, a different member length and a different
everything.

Building the same dome four times is cheaper per square foot than building
one dome four times the size, which is the opposite of how conventional
construction works.

THE LAYOUT

Domes want to be far enough apart that the ground between them drains and
close enough that walking between them in the rain is acceptable.

A cluster round a shared yard reads well and shelters the yard. A row reads
badly, because a row of round things looks accidental.

WHAT IS SHARED

The services. One connection, one tank, one panel, spurred to each pad -- the
reference build prices a share of one hub panel at four ways.

The expensive machinery. One workshop with the good tools. One kitchen, if
the domestic arrangement allows it.

WHAT IS NOT

The heating. Four small buildings heated separately cost more than one large
one heated throughout, and this is the compound's real penalty. Four
envelopes is more envelope than one.

THE ARGUMENT THIS LOSES

The 41 percent envelope saving is per building, and four buildings have four
envelopes. A compound gives up a good part of the shape's thermal advantage
in exchange for modularity.

Worth saying, because the compound is usually presented as all upside.
