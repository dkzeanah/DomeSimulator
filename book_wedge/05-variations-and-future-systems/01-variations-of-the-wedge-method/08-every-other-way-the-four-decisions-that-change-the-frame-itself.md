# Every other way: the four decisions that change the frame itself

Which way the wedge points, how many sectors the log splits into, how big the tree was, and which way the triangle pinwheels. Every one of them is irreversible once the first panel is cut, and every one has a figure in this book.

EVERY OTHER WAY OF DOING IT

    
    wedge orientation = point_dome_in             both points inward, toward the centre; seam key 2.80 in   <- the reference build
    wedge orientation = point_panel_in            points apart, each into its own triangle; seam key 11.67 in
    wedge orientation = point_dome_out            both points outward, at the sky; seam key 6.27 in
    wedge orientation = point_panel_out           points toward each other, across the seam; seam key 11.67 in
    radial splits = 4                             four sectors: a quarter of the log, and a very deep wall; seam key 7.05 in
    radial splits = 6                             six sectors: a fat wedge, a deep wall; seam key 4.30 in
    radial splits = 8                             eight sectors: the reference build; seam key 2.80 in   <- the reference build
    radial splits = 12                            twelve sectors: thin sticks, more of them; seam key 1.25 in
    radial splits = 16                            sixteen sectors: staves, and a seam channel under half an inch; seam key 0.47 in
    trunk diameter in = 8.0                       an eight-inch trunk: a slender frame; seam key 1.87 in
    trunk diameter in = 12.0                      a twelve-inch trunk: the reference build; seam key 2.80 in   <- the reference build
    trunk diameter in = 16.0                      a sixteen-inch trunk: heavy section, fewer trees; seam key 3.73 in
    panel joint handedness = clockwise            clockwise, seen from outside; seam key 2.80 in   <- the reference build
    panel joint handedness = counterclockwise     counterclockwise, seen from outside; seam key 2.80 in

These change the frame itself. Every other choice in this book can be made after the dome is standing; these cannot be made twice.

WHERE THESE NUMBERS COME FROM

the raw-wedge solver's own configuration space, applied to the reference build's own quantities. Nothing on this page is a rate quoted from outside the project, and nothing on it was typed: regenerate the whole table with `py -3.12 -m wedge_book.alternatives`.

There is no straw-bale row and no earthbag row, because this project cannot cost one. A table with a plausible number in it that came from nowhere is worse than a table with a gap.
