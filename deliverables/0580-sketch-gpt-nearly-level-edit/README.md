# sketch-gpt production edit

JSON is the complete camera, cast and dialogue source. EDL is a non-drop-frame cut list, not rendered media.

Floor support is modeled; camera/structure collision is off. Spline speed is time-parametric, not constant-distance. Faces use text-timed jaw motion, not audio phoneme sync.

Render via the registered sketch_gpt_pilot film. This package is a storyboard and edit export, not a finished episode.
