# Launchers

Double-click any of these. Each opens the tool from the project folder, and keeps
its window open if something goes wrong so you can read the error.

| Launcher | What it opens |
|---|---|
| `00 DomeSim Launcher (every tool).bat` | The main launcher: one window with a tab for every tool. |
| `01 Intelligence Dashboard.bat` | What the observer learned, playbooks, DeepSeek and the agent, in your browser. |
| `02 Project Agent (chat).bat` | Chat with the project's automation agent in a console. |
| `Two Trees Codex Launcher.bat` | The launcher with the extra book tab. |
| `Raw Wedge Simulator.bat` | The live raw-wedge solver and 3-D dome. |
| `Raw Wedge Simulator (older single file).bat` | The earlier single-file solver. |
| `2V Multiview Viewer.bat` | The 2V dome in several projections at once. |
| `Wedge Teleprompter.bat` | The persuasive presentation, teleprompter style. |
| `Dome Creator.bat` | Walkable build-a-home dome customiser. |
| `Dome Forge.bat` | The layered dome builder. |
| `Dome Composer.bat` | Furnish a dome scene. |
| `Dome Park.bat` | Serviced pads and the dome network. |
| `Triangle Infill.bat` | The 3-D cutting tool: fill or cover a triangle, click any numbered piece for its exact lengths and saw setup, and watch each cut and its offcut. Also the floor base: the pentagon platform under the dome, in every pattern and material, with its cut list, span checks and piers. |
| `Seed Console.bat` | The seed dome's cost calculator in 3-D. |
| `Jig Focus World.bat` | The fabrication jig, up close. |
| `Assembly Line.bat` | The factory simulation (investor demo). |
| `Assembly Line (simple).bat` | The simpler factory simulation. |
| `Book Studio.bat` | The desk where the wedge book is built. |
| `Beat Studio.bat` | Sequence rendered beats into a cut. |
| `Presenter Studio.bat` | Text to explainer video for the 3-D worlds. |
| `Local Voice Studio.bat` | Record and build the narration voice. |
| `Video Review.bat` | Review rendered films and leave notes. |
| `Masterclass - 2V.bat` | The 2V teaching world. |
| `Masterclass - Hexagonal Dome.bat` | The hexagonal-dome teaching world. |
| `Masterclass - Zome.bat` | The zome teaching world. |
| `Masterclass - Assembly Line Energy.bat` | The assembly-line energy lesson. |
| `Masterclass - Dome Build.bat` | Start-to-finish 2V construction. |
| `Masterclass - Frankendome.bat` | The franken-dome build lesson. |
| `Masterclass - Frankendome Hype.bat` | The Frankendome montage. |
| `Masterclass - Hubless Compound Cut.bat` | The compound-cut lesson. |
| `Masterclass - Twenty Dollar Pine 2.bat` | The Twenty Dollar Pine, part two. |
| `Web App (dev).bat` | The website (book gate and dome network), for development. Needs Node.js. |

Need: Python 3.12 (the `py` launcher). The DeepSeek panels need `DEEPSEEK_API_KEY` set in your
Windows environment variables.
